# 视频播放器使用说明

## 📝 简介

这是一个简单的 HTML5 视频播放器,可以**递归搜索当前目录及所有子目录**下的所有 MP4 视频文件,并提供便捷的播放界面。

## 🚀 快速开始

### 1. 准备视频文件

将你的 MP4 视频文件放在任意子目录中:

```bash
# 视频可以在任何位置,服务器会递归搜索
# 例如:
project/
  ├── movies/video1.mp4
  ├── clips/video2.mp4
  └── download/video3.mp4
```

### 2. 启动服务器

```bash
python server.py
```

### 3. 打开浏览器

访问: http://localhost:8000/index.html

或直接访问: http://localhost:8000

## ✨ 功能特性

- ✅ **递归搜索**当前目录及所有子目录下的 MP4 文件
- ✅ 显示视频的完整路径和文件大小
- ✅ 美观的视频列表界面
- ✅ 点击视频名称即可播放
- ✅ 支持视频进度条拖动
- ✅ 支持全屏播放
- ✅ 响应式设计,适配不同屏幕尺寸
- ✅ 使用 Video.js 专业视频播放器
- ✅ 自动排除系统目录(.git, node_modules 等)

```
.
```

## 🔧 自定义配置

### 修改端口号

编辑 `server.py`,修改 `PORT` 变量:

```python
PORT = 8000  # 改为你想要的端口号
```

### 修改搜索目录

编辑 `server.py`,修改 `SEARCH_DIR` 变量:

```python
SEARCH_DIR = "."  # 当前目录,可以改为其他目录
```

### 排除特定目录

编辑 `server.py`,修改 `EXCLUDE_DIRS` 变量:

```python
EXCLUDE_DIRS = {'.git', 'node_modules', '__pycache__', '.venv', 'venv', 'env'}
```

## ❓ 常见问题

### Q: 为什么需要启动服务器?

A: 由于浏览器的安全限制,直接打开 HTML 文件无法读取本地目录。需要通过 HTTP 服务器来提供文件访问。

### Q: 支持哪些视频格式?

A: 目前只支持 MP4 格式。如需支持其他格式(如 webm, mkv),需要修改代码中的文件扩展名过滤。

### Q: 视频列表是空的怎么办?

A: 请检查:
1. 当前目录及子目录下是否有 `.mp4` 文件
2. 视频文件是否在被排除的目录中(如 .git, node_modules)
3. 服务器是否正常运行
4. 查看服务器启动时显示的文件统计信息

### Q: 视频无法播放?

A: 可能的原因:
1. 视频编码不兼容(建议使用 H.264 编码)
2. 文件路径错误
3. 浏览器不支持该格式
