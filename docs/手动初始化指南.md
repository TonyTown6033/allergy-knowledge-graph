# Notion 数据库手动初始化指南

## 问题说明

由于 Notion API 的限制，通过 API 创建的空数据库不会保留属性定义。需要在 Notion Web 界面中手动添加至少一个属性。

## 解决方案：手动初始化（5分钟完成）

### 步骤 1：打开你的 Notion 页面

访问你之前提供的页面：
https://www.notion.so/2ef70e3608b980c88039fd4473fe7bd5

你应该能看到三个新创建的数据库：
- 过敏知识图谱 - Ontology (本体)
- 过敏知识图谱 - Claims (观点)
- 过敏知识图谱 - Evidence (证据)

### 步骤 2：为 Ontology 数据库添加属性

1. 打开 **"过敏知识图谱 - Ontology (本体)"** 数据库
2. 点击表格顶部的 **"+ 添加列"** 或第一列右边的空白处
3. 依次添加以下属性（**属性名称必须完全一致**）：

| 属性名称 | 类型 | 说明 |
|---------|------|------|
| **名称** | Title (标题) | 第一列自动是标题类型 |
| **ID** | Text (文本) | 节点唯一标识 |
| **英文名** | Text (文本) | 英文名称 |
| **类别** | Select (选择) | 添加选项：过敏原、疾病、症状、检查、治疗、生物标志物、其他 |
| **别名** | Text (文本) | 别名列表 |
| **描述** | Text (文本) | 节点描述 |
| **父节点** | Text (文本) | 父节点ID |

**注意事项：**
- "名称"是第一列，默认就是 Title 类型，不用手动添加
- "类别"是 Select 类型，需要添加7个选项（可以暂时不添加，后续会自动创建）
- 其他都是 Text 类型

### 步骤 3：为 Claims 数据库添加属性

1. 打开 **"过敏知识图谱 - Claims (观点)"** 数据库
2. 添加以下属性：

| 属性名称 | 类型 | 说明 |
|---------|------|------|
| **标题** | Title (标题) | 第一列 |
| **内容** | Text (文本) | 观点内容 |
| **极性** | Select (选择) | 添加选项：支持、反驳、中立 |
| **关联概念** | Multi-select (多选) | 关联的本体节点 |
| **来源标题** | Text (文本) | 文献标题 |
| **来源链接** | URL (链接) | 文献链接 |

### 步骤 4：为 Evidence 数据库添加属性

1. 打开 **"过敏知识图谱 - Evidence (证据)"** 数据库
2. 添加以下属性：

| 属性名称 | 类型 | 说明 |
|---------|------|------|
| **标题** | Title (标题) | 第一列 |
| **内容** | Text (文本) | 证据内容 |
| **来源标题** | Text (文本) | 文献标题 |
| **来源链接** | URL (链接) | 文献链接 |
| **页码** | Number (数字) | 页码 |

### 步骤 5：验证并开始同步

完成属性添加后，返回终端运行：

```bash
# 检查数据库结构
uv run python check_notion_schema.py

# 如果显示属性正常，继续同步
uv run python main.py ontology sync

# 上传观点
uv run python upload_results.py results.json
```

## 快捷方式

如果你觉得手动添加属性太麻烦，可以：

1. **只添加标题列**（第一列自动是 Title）
2. **添加一个测试数据行**（随便填点内容）
3. 运行同步命令，程序会自动创建缺失的属性

例如，在 Ontology 数据库中：
- 在"名称"列随便输入"测试"
- 点击回车创建一行
- 然后运行 `uv run python main.py ontology sync`

程序会自动创建所需的其他属性！

## 常见问题

**Q: 为什么不能通过 API 自动创建属性？**
A: 这是 Notion API 的限制。空数据库无法通过 API 设置属性，必须有至少一列（Title）才能开始添加数据。

**Q: 我添加错了属性名怎么办？**
A: 在 Notion 中重命名属性即可，或者删除重建。

**Q: Select 类型的选项需要提前创建吗？**
A: 不需要！首次添加数据时会自动创建选项。

## 预计时间

- 最快方式：1分钟（每个数据库只添加标题列）
- 完整方式：5分钟（手动添加所有属性）

完成后立即可以开始同步数据！
