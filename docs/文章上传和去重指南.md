# 文章上传和去重功能指南

## 🎯 新功能

### 1. **文章全文上传**
- ✅ PDF 原文上传到 Notion Articles 数据库
- ✅ 保存完整文本内容
- ✅ 记录文件信息（路径、大小、MD5）

### 2. **MD5 去重机制**
- ✅ 自动计算文件 MD5 哈希值
- ✅ 本地追踪已处理文件（`.processed_files.json`）
- ✅ 避免重复提取和上传
- ✅ 支持强制重新处理

### 3. **完整关联**
```
Article (文章全文)
   ↓ 链接
Claims (观点) ←→ Evidence (证据)
   ↓
Ontology (本体概念)
```

## 🚀 快速开始

### 步骤 1：创建 Articles 数据库

```bash
uv run python create_articles_database.py 2ef70e3608b980c88039fd4473fe7bd5
```

会输出：
```
✓ 创建成功
数据库 ID: xxxxx...

请在 .env 文件中添加：
NOTION_ARTICLES_DB_ID=xxxxx...
```

### 步骤 2：更新 .env 文件

编辑 `.env` 文件，添加：
```bash
NOTION_ARTICLES_DB_ID=你的数据库ID
```

### 步骤 3：上传文章

```bash
# 首次处理
uv run python upload_complete.py "your_file.pdf"

# 如果已处理过，会提示
# 强制重新处理：
uv run python upload_complete.py "your_file.pdf" --force
```

## 📊 Articles 数据库结构

| 列名 | 类型 | 说明 |
|------|------|------|
| **Name** | Title | 文章标题（文件名） |
| **MD5** | Text | 文件 MD5 哈希值（用于去重） |
| **文件路径** | Text | 文件在本地的路径 |
| **文件大小** | Number | 文件大小（字节） |
| **来源链接** | URL | 可选的外部链接 |
| **页面内容** | - | 文章全文（存储在页面 body 中） |

## 🔍 工作流程

### 完整流程（`upload_complete.py`）

```
1. [去重检查]
   计算 MD5 → 检查是否已处理 → 提示用户

2. [提取内容]
   提取 PDF 全文 → 提取观点和证据

3. [上传文章]
   上传全文到 Articles 数据库 → 获得文章 ID

4. [上传证据]
   上传所有证据到 Evidence 数据库

5. [上传观点]
   上传观点 → 关联证据 ID → 关联文章 ID

6. [记录追踪]
   保存处理记录到 .processed_files.json
```

## 🔧 高级功能

### 1. 强制重新处理

忽略去重，强制重新处理：

```bash
uv run python upload_complete.py file.pdf --force
```

### 2. 手动管理处理记录

处理记录存储在 `.processed_files.json`：

```json
{
  "a1b2c3d4...": {
    "file_name": "file.pdf",
    "file_path": "/path/to/file.pdf",
    "md5": "a1b2c3d4...",
    "processed_at": "2026-01-22T00:00:00",
    "notion_article_id": "page_id...",
    "claims_count": 5,
    "evidence_count": 5
  }
}
```

可以手动删除某条记录来重新处理该文件。

### 3. 在 Notion 中查看

**Articles 数据库：**
- 打开数据库查看所有已上传文章
- 点击文章可查看完整原文
- MD5 列用于去重标识

**Claims 数据库：**
- `来源链接` 字段会指向对应的 Article 页面
- 点击可直接跳转到原文

## ⚠️ 注意事项

### 1. Notion API 限制

- **文本长度**：每个 block 最多 2000 字符
- **Block 数量**：一次最多添加 100 个 blocks
- **超长文章**：会自动截取前 50000 字符

### 2. MD5 计算

- MD5 基于**文件内容**计算
- 文件名改变不影响 MD5
- 文件内容改变会产生新 MD5

### 3. 处理记录

- 本地存储在 `.processed_files.json`
- **不要提交到 git**（已在 .gitignore 中）
- 删除此文件会丢失所有处理历史

## 🐛 故障排除

**Q: 提示 "Articles 数据库ID未配置"？**
A: 确保 `.env` 中有 `NOTION_ARTICLES_DB_ID=...`

**Q: 文章内容没有显示？**
A: 检查 Notion 页面 body，内容存储在段落 blocks 中

**Q: MD5 去重不工作？**
A: 检查 `.processed_files.json` 是否存在且有读写权限

**Q: 想清空处理历史？**
A: 删除 `.processed_files.json` 文件
