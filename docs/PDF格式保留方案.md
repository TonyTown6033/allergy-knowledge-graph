# PDF 格式保留方案

## 📋 问题说明

当前 `upload_complete.py` 提取 PDF 文本并上传到 Notion 时，会丢失原始格式：
- ❌ 丢失排版
- ❌ 丢失图片
- ❌ 丢失表格格式
- ❌ 变成纯文本

## 💡 解决方案对比

### 方案 1：手动上传 PDF（推荐）⭐

**特点：**
- ✅ 完美保留格式
- ✅ 可以在 Notion 中直接查看 PDF
- ✅ 支持批注和高亮
- ⚠️ 需要手动操作

**步骤：**
```bash
# 1. 创建文章记录（不上传文本）
uv run python upload_with_pdf.py "file.pdf"

# 2. 脚本会输出 Notion 页面链接
# 3. 在浏览器中打开链接
# 4. 将 PDF 文件拖拽到页面中
```

**优势：**
- 保留完整的 PDF 格式
- 可以直接在 Notion 中阅读
- 支持 Notion 的 PDF 预览功能

---

### 方案 2：纯文本上传（当前方式）

**特点：**
- ✅ 全自动，无需手动操作
- ✅ 可以搜索文本内容
- ❌ 丢失格式
- ❌ 适合纯文字文档

**使用：**
```bash
uv run python upload_complete.py "file.pdf"
```

**适用场景：**
- 纯文字文档
- 需要全文搜索
- 不在意格式

---

### 方案 3：混合方式（推荐）⭐⭐⭐

**最佳实践：同时保存 PDF 和提取内容**

**步骤：**
1. 使用 `upload_with_pdf.py` 创建文章页面
2. 手动上传 PDF 文件到页面
3. 提取的观点和证据自动关联到该页面

**优势：**
- ✅ PDF 格式完整保留
- ✅ 观点和证据自动提取
- ✅ 完整的知识图谱关联
- ✅ 可以对照原文查看

---

## 🚀 推荐工作流程

### 工作流 A：注重格式（文献阅读）

```bash

uv run python upload_with_pdf.py "重要文献.pdf"

# 2. 打开输出的 Notion 链接

# 结果：

```

```bash
# 结果：
# - Articles 中有文本内容（无格式）
# - 快速建立知识库
```

## 🔧 技术说明

### 为什么不能自动上传 PDF？

Notion API 的文件上传流程复杂：
1. 需要先申请上传 URL
2. 上传文件到临时存储
3. 将文件链接添加到页面

目前的限制：
- Notion Python SDK 对文件上传支持有限
- 需要额外的认证和权限
- 实现复杂度高

### 手动上传很简单

在 Notion 页面中：
1. 打开文章页面
2. 输入 `/file` 或直接拖拽 PDF
3. PDF 自动上传并显示

## 💡 使用建议

### 重要文献（<10 篇）
使用**方案 1 或 3**：
```bash
uv run python upload_with_pdf.py "重要指南.pdf"
# 然后手动上传 PDF
```

### 大量文献（>50 篇）
使用**方案 2**：
```bash
# 批量处理
for pdf in *.pdf; do
    uv run python upload_complete.py "$pdf"
done
```

### 混合场景
- 重要的：手动上传 PDF
- 一般的：纯文本提取

## ❓ 常见问题

**Q: PDF 文件会占用 Notion 存储空间吗？**
A: 是的。Notion 免费版有存储限制，注意空间使用。

**Q: 可以批量上传 PDF 吗？**
A: Notion 支持多文件拖拽上传。可以一次性拖拽多个 PDF。

**Q: 上传的 PDF 可以删除吗？**
A: 可以。在 Notion 页面中删除文件块即可。

**Q: 纯文本上传能改成 PDF 吗？**
A: 可以。编辑 Articles 页面，删除文本内容，上传 PDF 文件。
