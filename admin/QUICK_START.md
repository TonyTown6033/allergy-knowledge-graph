# 🚀 后台管理系统 - 快速启动指南

## 方式一：使用启动脚本（推荐）

```bash
# 在项目根目录执行
./start_admin.sh
```

## 方式二：手动启动

```bash
# 1. 安装 Flask（如果还没安装）
pip install flask
# 或
pip3 install flask

# 2. 启动后台
python admin/app.py
# 或
python3 admin/app.py
```

## 方式三：使用 uv

```bash
# 先确保 Flask 已安装到项目环境
uv pip install flask

# 然后启动
uv run python admin/app.py
```

---

## ✅ 访问管理后台

启动成功后，打开浏览器访问：

```
http://localhost:5000
```

你会看到：
- 📊 **仪表板**：数据统计和快速操作
- 📄 **文章管理**：查看和管理所有文章
- 💬 **观点管理**：查看和搜索医学观点  
- 🧬 **本体管理**：管理医学概念本体
- 🔄 **数据同步**：批量上传和生成图谱

---

## 🎯 与前台系统的关系

- **后台管理**：http://localhost:5000（数据管理）
- **前台展示**：http://localhost:8000（知识图谱展示）

两个系统可以**同时运行**，互不干扰。

## 🔧 常见问题

### 1. 端口被占用

如果 5000 端口被占用，可以修改 `admin/app.py` 最后一行：

```python
app.run(debug=True, host='0.0.0.0', port=5001)  # 改成 5001 或其他端口
```

### 2. Flask 安装失败

```bash
# 尝试使用 pip3
pip3 install flask

# 或指定国内镜像
pip install flask -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 无法访问

检查：
- 防火墙是否阻止了 5000 端口
- 是否使用了正确的地址（localhost 或 127.0.0.1）
- 终端是否显示 "Running on http://..."
