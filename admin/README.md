# 过敏知识图谱 - 后台管理系统

一个简洁美观的后台管理界面，用于管理过敏知识图谱系统的文章、观点、本体和数据同步。

## ✨ 功能特性

### 📊 仪表板
- 实时数据统计（文章数、观点数、图谱节点数等）
- 系统状态监控
- 快速操作入口

### 📄 文章管理
- 查看所有文章列表
- 查看文章详情（标题、观点数、证据数、上传状态）
- 支持上传新文章（开发中）

### 💬 观点管理
- 查看所有医学观点
- 按关键词搜索观点
- 查看观点极性（支持/反驳/中立）
- 关联到原文献

### 🧬 本体管理
- 查看所有医学概念本体（27个节点）
- 按类别筛选（过敏原、疾病、免疫分子、治疗、检测等）
- 查看中英文名称、描述和别名

### 🔄 数据同步
- 批量上传文章到 Notion
- 从本地或 Notion 生成图谱数据
- 实时显示同步进度和状态

## 🚀 快速开始

### 1. 安装依赖

```bash
# 在项目根目录下
pip install flask

# 或使用 uv
uv pip install flask
```

### 2. 启动后台管理系统

```bash
cd admin
python app.py

# 或使用 uv
uv run python admin/app.py
```

### 3. 访问管理界面

打开浏览器访问：
```
http://localhost:5000
```

## 🔧 API 接口

后台管理系统提供以下 RESTful API：

### 仪表板
- `GET /api/dashboard/stats` - 获取统计数据

### 文章
- `GET /api/articles/list` - 获取文章列表
- `POST /api/articles/upload` - 上传新文章

### 观点
- `GET /api/claims/list` - 获取观点列表

### 本体
- `GET /api/ontology/list` - 获取本体列表

### 同步
- `POST /api/sync/export-graph` - 生成图谱数据
- `POST /api/sync/upload-batch` - 批量上传文章

## 📝 使用说明

### 批量上传文章

1. 进入"数据同步"页面
2. 点击"开始批量上传"按钮
3. 等待上传完成（可能需要较长时间）
4. 查看上传进度和结果

### 生成图谱数据

1. 进入"数据同步"页面
2. 选择数据源：
   - "从本地生成"：使用 `results.json`
   - "从 Notion 生成"：从 Notion 数据库拉取
3. 等待生成完成
4. 查看生成结果

### 查看数据统计

1. 进入"仪表板"页面
2. 查看统计卡片和系统状态
3. 点击"刷新"按钮更新数据

## ⚙️ 配置说明

后台管理系统会自动读取项目根目录的配置：
- `.env` 文件（Notion 和 OpenAI 配置）
- `results.json`（本地文章数据）
- `graph_data.json`（图谱数据）
- `.processed_files.json`（上传记录）

确保这些文件存在并配置正确。

## 🚨 注意事项

1. **端口冲突**: 后台管理系统使用 5000 端口，前台系统使用 8000 端口
2. **文件上传**: 上传文件最大 50MB
3. **长时间操作**: 批量上传可能需要较长时间，请耐心等待
4. **浏览器兼容性**: 建议使用现代浏览器（Chrome、Firefox、Safari）

---

## 🔒 安全建议

1. **生产环境**: 
   - 修改 `SECRET_KEY`
   - 添加用户认证
   - 使用 HTTPS

2. **访问控制**:
   - 限制管理后台访问 IP
   - 添加登录验证

3. **文件上传**:
   - 验证文件类型和大小
   - 扫描恶意文件
