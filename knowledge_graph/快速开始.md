# 3D 知识图谱 - 快速开始

## 🚀 一分钟启动

### 方法 1：使用启动脚本（推荐）

```bash
cd knowledge_graph
./start.sh
```

### 方法 2：手动启动

```bash
cd knowledge_graph
uv run python api_server.py
```

### 3. 打开浏览器

访问：**http://localhost:8001/**

---

- **拖拽旋转** - 鼠标左键

- **点击节点** - 查看详情
- **筛选** - 右上角控制面板

## 📊 数据来源

图谱实时从以下来源获取数据：

1. **本体节点** - 本地定义（27个医学概念）
2. **观点节点** - Notion Claims 数据库
3. **证据节点** - Notion Evidence 数据库
4. **关联关系** - 自动分析和建立

---

## 🎯 使用场景演示

### 场景 1：探索概念关系

1. 启动图谱
2. 找到"IgE"节点（蓝色）
3. 查看连接到它的观点（绿色/红色/灰色）
4. 点击观点查看详情

### 场景 2：分析观点分布

1. 使用右上角筛选
2. 选择"只显示观点"
3. 按颜色区分：
   - 绿色 = 支持性观点
   - 红色 = 反驳性观点
   - 灰色 = 中立观点

### 场景 3：类别聚类

1. 筛选特定类别（如"过敏原"）
2. 查看该类别下的所有概念
3. 观察它们的关联关系

## 💡 提示

1. **首次加载** - 可能需要几秒钟获取数据
2. **节点过多** - 使用筛选功能聚焦特定区域
3. **卡顿** - 关闭自动旋转（点击"暂停旋转"）
4. **找不到节点** - 使用"重置视图"回到初始位置

## ❓ 常见问题

**Q: 页面空白？**
A: 
1. 检查 API 服务器是否运行
2. 打开浏览器控制台查看错误
3. 确认端口 8001 未被占用

**Q: 看不到观点节点？**
A: 
1. 确保已运行 `upload_auto.py` 上传观点
2. 检查 Notion Claims 数据库是否有数据

**Q: 如何停止服务器？**
A: 在终端按 `Ctrl + C`
