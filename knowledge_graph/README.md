# 3D 知识图谱可视化系统

## 🎨 功能特性

### 核心功能
- ✅ **3D 可视化** - 使用 Three.js 和 Force-Graph 3D 渲染
- ✅ **实时数据** - 从 Notion 数据库实时获取数据
- ✅ **交互探索** - 旋转、缩放、拖拽查看
- ✅ **节点详情** - 点击节点查看详细信息
- ✅ **智能筛选** - 按类型、类别筛选节点
- ✅ **关联展示** - 可视化观点与概念的关联关系

### 视觉效果
- 🎨 不同类别的本体节点用不同颜色区分
- 🎨 观点节点根据极性（支持/反驳/中立）着色
- 🎨 动态粒子流显示关联关系
- 🎨 自动旋转和平滑过渡动画
- 🎨 渐变背景和毛玻璃效果

## 🚀 快速开始

### 1. 启动 API 服务器

```bash
cd knowledge_graph
uv run python api_server.py
```

服务器启动后会显示：
```
======================================================================
知识图谱 API 服务器
======================================================================

启动中...
端口: 8001

API 端点:
  GET /api/ontology    - 获取本体节点
  GET /api/claims      - 获取观点数据
  GET /api/evidence    - 获取证据数据
  GET /api/graph       - 获取完整图谱数据
  GET /api/stats       - 获取统计信息

访问前端: http://localhost:8001/
按 Ctrl+C 停止服务器
======================================================================
```

### 2. 访问前端页面

在浏览器中打开：
```
http://localhost:8001/index.html
```

或者直接：
```
http://localhost:8001/
```

## 🎮 使用说明

### 基本操作

| 操作 | 方法 |
|------|------|
| **旋转视图** | 鼠标左键拖拽 |
| **缩放** | 鼠标滚轮 |
| **平移** | 鼠标右键拖拽 |
| **查看详情** | 点击节点 |
| **重置视图** | 点击"重置视图"按钮 |
| **暂停旋转** | 点击"暂停旋转"按钮 |

### 筛选功能

**节点类型筛选：**
- 全部 - 显示所有节点
- 本体概念 - 只显示医学概念节点
- 观点 - 只显示从文献中提取的观点

**概念类别筛选：**
- 可以按 8 种类别筛选本体节点
- 免疫球蛋白、过敏原、疾病、症状等

### 查看详情

点击任意节点，左下角会显示详情面板：
- **本体节点**: 显示类别、描述、ID
- **观点节点**: 显示极性、完整标题

## 📊 图谱结构说明

### 节点类型

**1. 本体节点（Ontology）**
- 形状：较大的球体
- 颜色：根据类别（8种颜色）
- 数量：27个核心医学概念

**2. 观点节点（Claims）**
- 形状：较小的球体
- 颜色：根据极性
  - 🟢 绿色 = 支持
  - 🔴 红色 = 反驳
  - ⚪ 灰色 = 中立
- 数量：从文献中提取的观点

### 连线类型

**1. 概念关联（Concept Relation）**
- Claims → Ontology
- 表示观点关联的医学概念

**2. 父子关系（Parent Relation）**
- Ontology → Ontology
- 表示概念的层级关系（如 IgG4 → IgG）

## ⚙️ 配置说明

### API 端口

默认使用 8001 端口。如需修改，编辑 `api_server.py`：

```python
PORT = 8001  # 改为你想要的端口
```

同时修改 `app.js` 中的 API 地址：

```javascript
const API_BASE = 'http://localhost:8001';
```

### 数据刷新

图谱数据在页面加载时获取。如需刷新：
- 方法 1: 刷新浏览器页面 (F5)
- 方法 2: 重启 API 服务器

## 🐛 故障排除

### Q: 页面显示"加载失败"？
A: 确保 API 服务器正在运行：`python api_server.py`

### Q: 看不到任何节点？
A: 
1. 检查 Notion 数据库是否有数据
2. 检查 .env 配置是否正确
3. 查看浏览器控制台的错误信息

### Q: 节点太多，画面很乱？
A: 使用筛选功能，只显示特定类型或类别的节点

### Q: 性能问题？
A: 
1. 减少返回的数据量（修改 `page_size`）
2. 使用筛选功能
3. 关闭自动旋转

## 📝 开发说明

### 添加新的节点类型

在 `app.js` 中的 `COLORS` 对象添加配色：

```javascript
const COLORS = {
    new_type: {
        'category_name': '#color_code'
    }
};
```

### 自定义节点样式

修改 `createGraph()` 函数中的节点配置：

```javascript
.nodeVal(node => node.type === 'ontology' ? 8 : 5)  // 节点大小
.nodeColor(node => ...)  // 节点颜色
.nodeOpacity(0.9)        // 透明度
```

### 修改力导向布局

```javascript
graph
    .d3Force('charge').strength(-120)  // 斥力
    .d3Force('link').distance(30)       // 连线长度
```
